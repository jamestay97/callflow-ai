# Background Music

Drop royalty-free MP3 files here to replace the auto-generated placeholders:

| File | Used in |
|------|---------|
| `upbeat.mp3` | Intro & outro scenes |
| `calm.mp3` | Story scenes (quiet background) |
| `celebrate.mp3` | Celebration / recap scenes |

**Free music sources:**
- [YouTube Audio Library](https://studio.youtube.com/channel/UC/music)
- [Pixabay Music](https://pixabay.com/music/)
- [Free Music Archive](https://freemusicarchive.org/)

If these files are missing, the bot generates simple tone loops automatically.

**Tip:** Keep tracks 15–30 seconds — they loop per scene. Use instrumental only so narration stays clear.
